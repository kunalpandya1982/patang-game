# Patang (પતંગ)

A rooftop kite-battle game where children cut rival kites by speaking Gujarati out loud, and teach every new word to Mithu the parrot.

**Play:** https://kunalpandya1982.github.io/patang-game/

- Recordings made in the game (a child's voice for Mithu, a grown-up's voice for the guide) stay in the browser on that device. Nothing is uploaded.
- This repository holds only the published game. It is built from a private working repository.
